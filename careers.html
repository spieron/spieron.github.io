Open roles

i.

Data Engineer

Full-time Cloudera platform

You will build, deploy and manage batch and streaming data pipelines on the Cloudera platform, and own the reliability of data as it flows from source systems into the lakehouse.

Responsibilities

  • Build, develop and optimize data pipelines in Apache Spark, Apache Flink and Apache Iceberg environments.
  • Own data ingestion and streaming with Apache NiFi (Cloudera Data Flow) and Apache Kafka, ensuring data-flow reliability.
  • Run analytics on streaming data with continuous SQL in SQL Stream Builder.
  • Manage Iceberg lakehouse tables: schema and partition evolution, snapshot rollback, compaction and ACID across streaming and batch.
  • Tune and monitor Spark applications, identifying and resolving performance issues.

Requirements

  • Hands-on experience developing Apache Spark applications.
  • Experience with stream processing in Apache Flink.
  • Experience building ingestion flows with Apache NiFi and working with Apache Kafka.
  • Familiarity with Apache Iceberg and with query engines such as Hive and Trino.
  • Strong SQL and Python skills.
  • Comfortable working in Linux environments.
  • Familiarity with Kubernetes.

Advantages

Cloudera Data Engineer certification Cloudera Data Lakehouse Engineer certification Cloudera Data Operator certification Trino Apache Ozone

ii.

Cloudera Systems Administrator

Full-time Cloudera on premises

You will install, operate and maintain Cloudera clusters on premises, keeping them secure, available and performant. From cluster administration and security to capacity, monitoring, tuning and upgrades, you will own the health of the platform.

Responsibilities

  • Administer Cloudera clusters with Cloudera Manager: install, configure, operate and troubleshoot services.
  • Secure the platform: Kerberos, Auto-TLS, directory services (LDAP / Active Directory / FreeIPA), Apache Ranger policies, Apache Atlas, Knox single sign-on and data-at-rest encryption.
  • Plan and manage capacity: adding and decommissioning nodes, YARN queues and resource management.
  • Monitor the environment with Cloudera Manager and Cloudera Observability, configure alerting, and handle incidents.
  • Tune platform performance and work through logs and diagnostics to resolve problems.
  • Prepare for and carry out upgrades, including backing up Cloudera Manager and its database.

Requirements

  • Linux system administration experience; strong Linux proficiency is a must.
  • Knowledge of directory services, TLS and Kerberos.
  • Scripting in Python and Bash.
  • Hands-on experience with Kubernetes.
  • Basic SQL.

Advantages

Cloudera Administrator on premises certification Hands-on Cloudera Manager experience Cloudera Manager REST API High availability Rolling upgrades Cloudera on cloud administration AWS / Azure Ansible OpenShift

iii.

Data Architect

Full-time Cloudera platform

You will design the systems and data infrastructure that let organizations extract, organize and securely access their data, from the edge through streaming and analytics to AI. You will work across teams to choose the right technology for each need.

Responsibilities

  • Design data platform architectures on Cloudera covering streaming, data engineering, data warehousing, operational data and AI.
  • Identify internal and external data sources and work across departments to choose the optimal technology and data solution.
  • Apply modern data architecture approaches such as data lakehouse, data mesh and data fabric.
  • Select the right components: Spark, Flink and Kafka for streaming; HDFS and Ozone for storage; Hive and Impala for warehousing; HBase, Phoenix, Kudu and Solr for operational data.
  • Design security architecture with Kerberos, TLS, Apache Ranger, Apache Atlas and Knox.
  • Plan cluster sizing, scalability, fault tolerance and disaster recovery, and choose between on-premises and cloud deployment, including containers and Kubernetes.

Requirements

  • Experience as an architect, development team lead or senior data engineer on big data or streaming applications.
  • Working knowledge of HDFS, Spark, Kafka, Hive / Impala, data formats and relational databases.
  • Understanding of distributed systems: batch vs. real-time processing, fault tolerance and scalability.
  • Experience with Kubernetes and containerized platforms, and with Linux environments.
  • Ability to collaborate across departments and present architecture to technical and business stakeholders.

Advantages

Cloudera Generalist certification Trino Agentic AI with Cloudera AI

iv.

ML Engineer

Full-time Cloudera AI

You will turn enterprise data into production machine-learning models on Cloudera AI, owning the lifecycle from data preparation and training through deployment and monitoring, and guiding customers on MLOps.

Responsibilities

  • Load, explore, cleanse, join and analyze data to prepare it for modeling.
  • Train, evaluate and tune machine-learning models.
  • Deploy models on Cloudera AI, including as REST APIs, and manage them through the model registry.
  • Monitor deployed models for performance and data drift.
  • Track experiments with MLflow and build MLOps workflows with Git and CI/CD.
  • Provide MLOps guidance to customer teams.

Requirements

  • Hands-on experience training, evaluating and deploying machine-learning models.
  • Strong Python, including PySpark.
  • Understanding of MLOps practices: experiment tracking, model registry, deployment and monitoring.
  • Experience with Git, CI/CD, Docker and Kubernetes.
  • Comfortable working in Linux environments.

Advantages

Cloudera Machine Learning Engineer certification Cloudera Generative AI Engineer certification MLflow LLM fine-tuning and hosting Agentic AI with Agent Studio
