Open roles

i.

Data Engineer

Full-time On customer site Cloudera platform

You will work on-site at our customers, inside their data team, building and running the batch and streaming pipelines that move data from their source systems into the lakehouse. You own those pipelines end-to-end: from the first conversation about a new source, to the day the customer’s operations team takes them over.

Day to day

  • Take a new source system (database, files, message queue, API) and get its data into the lakehouse end-to-end: ingestion, validation, cleansing, enrichment and loading into Iceberg tables people can trust.
  • Build and maintain streaming flows (NiFi, Kafka, Flink / SQL Stream Builder) and batch jobs (Spark), and decide which one each use case needs.
  • Make sure nothing gets lost silently: bad records are rejected with a reason, can be inspected and replayed, and late or duplicate data is handled correctly.
  • Start the morning by checking what failed or ran late overnight. Find the root cause in logs, the Spark UI or the NiFi bulletins, fix it, and make sure it doesn’t happen again.
  • Tune slow or expensive jobs (partitioning, file sizes, joins, resources) and keep Iceberg tables healthy (schema and partition evolution, compaction, snapshot expiry, rollback when needed).
  • Work directly with the customer’s analysts, DBAs and platform admins. Clarify requirements, explain trade-offs, and push back when something won’t hold up in production.
  • Handle tickets and escalations for the pipelines you own, including opening and driving cases with vendor support.
  • Write runbooks and hand-over docs, and train the customer’s team so they can run what you built.

Requirements

  • Hands-on experience developing Apache Spark applications (PySpark or Scala).
  • Experience building ingestion and streaming pipelines with Apache Kafka and a flow / streaming tool (Apache NiFi, Apache Flink or similar).
  • Working knowledge of Apache Iceberg tables and an Iceberg catalog.
  • Strong SQL and Python.
  • SQL query engines: Trino and / or Impala.
  • Comfortable working in Linux: shell, logs, processes, permissions, networking basics.
  • Familiarity with Kubernetes and containers.
  • Comfortable working on-site with customers, with clear written and spoken communication.

Advantages

  • Cloudera Data Engineer certification

  • Apache Ozone

Linux / DevOps / GitOps Bonus

ii.

Cloudera Systems Administrator

Full-time On customer site Cloudera on premises

You will work on-site at our customers, as the platform owner of their on-premises Cloudera clusters. You keep the platform secure, available and performant, and you are the person the customer calls when something is slow, down or about to change.

Day to day

  • Start the day with health checks: service health, disks, HDFS / Ozone capacity, failed jobs, certificate expiry, alerts from overnight.
  • Handle incidents: find what broke from logs and metrics, restore service, keep the customer updated, and write the root-cause summary afterwards.
  • Onboard users, teams and new use cases: Kerberos principals, directory groups, Ranger policies, YARN queues, quotas, service accounts.
  • Open and drive cases with Cloudera support: collect diagnostic bundles, reproduce the issue, push it to a resolution, and apply the fix.
  • Plan and run changes with the customer: patches, upgrades, adding or decommissioning nodes, configuration changes. That includes backups, rollback plans and agreed maintenance windows.
  • Keep the platform secure in practice: TLS certificates, Kerberos, Ranger, Atlas, Knox SSO and encryption at rest. Answer the customer’s security and audit questions.
  • Plan capacity and tune performance together with the data teams using the cluster.
  • Automate anything you do twice (Bash / Python / Ansible, the Cloudera Manager API) and keep runbooks and documentation up to date.

Requirements

  • Strong Linux system administration is a must (RHEL / Rocky family, systemd, storage, networking, troubleshooting).
  • Working knowledge of directory services (LDAP / Active Directory / FreeIPA), TLS / PKI and Kerberos.
  • Scripting in Bash and Python.
  • Hands-on experience with Kubernetes and containers.
  • Basic SQL.
  • Comfortable working on-site with customers, handling incidents calmly and communicating clearly under pressure.

Advantages

Cloudera background Bonus

  • Hands-on Cloudera Manager administration, including the REST API
  • Cloudera Administrator on premises certification
  • High availability and rolling upgrades
  • Cloudera on cloud administration

Linux / DevOps / GitOps Bonus

  • Red Hat certification (RHCSA / RHCE)
  • Infrastructure as code and configuration management (Ansible / Terraform)
  • Git-based change management and GitOps (Argo CD / Flux)
  • OpenShift / Kubernetes administration

Also great

  • Monitoring and logging (Prometheus / Grafana / ELK / Zabbix)
  • Storage and networking (SAN / NAS, load balancers, DNS, firewalls)
  • Other Hadoop distributions or upstream Apache stacks (HDFS, Kafka, YARN)
  • AWS / Azure
  • Support, NOC or operations background

iii.

Data Architect

Full-time On customer site Cloudera platform

You will work on-site at our customers, as the technical lead who designs their data platform: from the edge through streaming and analytics to AI. You turn business needs into an architecture the customer can build, run and afford, and you stay close enough to the implementation to make sure it actually works.

Day to day

  • Run discovery with the customer: map the data sources, the consumers, the volumes, latency needs, security constraints and the existing landscape.
  • Turn that into a target architecture and a roadmap. Write the HLD / LLD, sizing, security design and disaster-recovery plan, and get them approved.
  • Choose the right tool for each need and explain why: streaming (Kafka, Flink, NiFi), processing (Spark), storage (HDFS / Ozone / object storage), lakehouse SQL (Impala / Trino over Iceberg) and operational data (HBase / Phoenix / Kudu / Solr). Be honest when another option is a better fit.
  • Build proofs of concept hands-on, to de-risk the design before the customer commits.
  • Guide and review the implementation team (Spieron’s and the customer’s), and catch design drift early.
  • Present to IT, security and business stakeholders. Run architecture and design reviews, and answer the hard questions.
  • Support pre-sales: scoping, effort estimates, technical parts of proposals and RFP answers.

Requirements

  • Experience as an architect, development team lead or senior data engineer on big data or streaming applications.
  • Working knowledge of Spark, Kafka, distributed storage (HDFS / Ozone / object storage), data formats (Parquet / ORC / Avro) and relational databases.
  • SQL query engines (Impala / Trino), and Iceberg tables and catalogs.
  • Understanding of distributed systems: batch vs. real-time, fault tolerance, scalability, consistency.
  • Experience with Kubernetes and containerized platforms, and with Linux.
  • Ability to work with many teams and to present architecture to both technical and business stakeholders.

Advantages

Cloudera background Bonus

  • Hands-on Cloudera (CDP) architecture or implementation
  • Cloudera Generalist certification
  • Agentic AI with Cloudera AI

Linux / DevOps / GitOps Bonus

  • Hands-on Linux administration background
  • Infrastructure as code and GitOps (Terraform / Ansible / Argo CD)
  • CI/CD for data platforms

Also great

  • Other data platforms (Databricks / Snowflake / AWS / Azure / GCP data services)
  • Data governance and catalogs (lineage, data quality, access control)
  • Pre-sales, consulting or RFP experience
  • Enterprise security and network architecture

iv.

ML Engineer

Full-time On customer site Cloudera AI

You will work on-site at our customers, next to their data scientists and platform teams, taking machine-learning and GenAI work from notebooks to production on Cloudera AI. You own the path from data preparation and training through deployment and monitoring, and you teach the customer’s team to run it themselves.

Day to day

  • Sit with the customer’s data scientists. Understand the use case and the data, and turn experimental notebooks into reliable, repeatable training pipelines.
  • Prepare data at scale: explore, cleanse, join and build features with PySpark / SQL, together with the data engineering team.
  • Train, evaluate and tune models, and be honest about whether a model is good enough for the business problem.
  • Deploy models as REST endpoints or batch scoring jobs. Manage versions in a model registry, and set up promotion, rollback and access.
  • Monitor models in production for performance and data drift, and investigate when predictions go wrong.
  • Build the MLOps plumbing: experiment tracking (MLflow), Git-based CI/CD for models, environments and containers.
  • Run GenAI / LLM pilots (RAG, fine-tuning, agents) on customer data, within the customer’s security constraints.
  • Coach customer teams on MLOps practice and write the docs they need.

Requirements

  • Hands-on experience training, evaluating and deploying machine-learning models to production.
  • Strong Python, including PySpark.
  • Understanding of MLOps practices: experiment tracking, model registry, deployment and monitoring.
  • Experience with Git, CI/CD, Docker and Kubernetes.
  • Comfortable working in Linux environments.
  • Comfortable working on-site with customers and explaining models to non-specialists.

Advantages

Cloudera background Bonus

  • Hands-on Cloudera AI (CML), including Agent Studio

Linux / DevOps / GitOps Bonus
